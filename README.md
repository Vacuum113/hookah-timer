# Кальянные таймеры

Веб-приложение для кальянной: таймеры по столам с несколькими интервалами
(забивка → прогрев чаши → работа чаши, уголь по кругу). MVP без сервера —
всё состояние хранится локально в браузере (localStorage).

## Как это работает

- **Зал** — круглые таймеры-столы, свободно расставленные по экрану.
  Тап по свободному столу запускает программу по умолчанию, долгое нажатие — выбор программы,
  тап по занятому открывает панель стола.
- **Интервалы** — у каждого свой режим перехода: автоматически или с подтверждением мастера.
  Повторы дают цикличные этапы («уголь каждые 20 мин × 3»).
- **После последнего интервала** стол не освобождается: кружок светится, счётчик идёт вверх,
  пока мастер не закроет кальян вручную.
- **Сигналы** — звук, подсветка карточки, счётчик «ждут мастера» и уведомления браузера.
- **Смена** — счётчик отданных кальянов, среднее время, разбивка по столам.

Таймеры считаются от абсолютного времени, поэтому переживают перезагрузку страницы
и сон вкладки. Открытые вкладки синхронизируются между собой.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
```

Деплой на GitHub Pages:

```bash
npm run deploy   # сборка + публикация в ветку gh-pages
```
