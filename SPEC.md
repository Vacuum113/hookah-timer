# Кальянные таймеры — ТЗ MVP

Согласовано с заказчиком 2026-09-09. Веб-приложение без сервера, всё хранится локально (localStorage).

## Пользователь
Кальянный мастер за баром. Принимает заказ → запускает таймер на нужный стол → по сигналам обслуживает столы.

## Модель данных

- **Зал** — набор столов, свободно расставленных по экрану (координаты в процентах холста,
  общий диаметр кружка). Раскладка тянется вместе с окном и не зависит от разрешения.
- **Стол** — содержит 0..N активных кальянов. На одном столе может одновременно работать несколько кальянов.
- **Кальян (сессия)** — экземпляр запущенной программы: ссылка на программу, текущий этап, время старта/паузы.
- **Программа** — именованный набор интервалов (напр. «Классика»). Есть программа по умолчанию.
- **Интервал** — название, длительность, флаг `autoNext` (переходить автоматически / ждать подтверждения мастера),
  цикличность (`repeat: N` — напр. «уголь каждые 20 мин × 3»).

## Поведение таймера

1. Тап по столу → запуск программы по умолчанию (1 клик). Долгий тап / меню → выбор другой программы.
2. По окончании интервала:
   - `autoNext = true` → следующий интервал стартует сам, сигнал звучит;
   - `autoNext = false` → таймер встаёт в состояние «требуется действие», сигнал повторяется,
     счётчик просрочки идёт вверх, пока мастер не подтвердит тапом.
3. Цикличные интервалы сигналят N раз внутри одного этапа (уголь/перемешать).
4. После последнего интервала стол НЕ освобождается автоматически: карточка светится,
   счётчик времени идёт вверх (+05:20), пока мастер не закроет кальян вручную.

## Сигналы
Звук + яркая подсветка/мигание карточки + счётчик «требуют внимания» вверху экрана
+ браузерные Notification API уведомления (чтобы дошло при свёрнутой вкладке).
Звук можно приглушить/выключить в настройках.

## Экраны

1. **Зал (рабочий режим)** — круглые таймеры-столы, свободно расставленные по экрану.
   На кружке: название стола, остаток времени, текущий этап, кольцо прогресса, значок «×N»
   при нескольких кальянах. Тап по свободному столу сразу запускает программу по умолчанию,
   долгое нажатие — выбор программы, тап по занятому открывает панель стола
   (подтвердить этап, пауза, +5 мин, закрыть).
2. **Редактор зала** — перетаскивание кружков по экрану с привязкой к шагу, добавить/удалить/
   переименовать стол, общий размер кружков, «разложить сеткой», сохранить/отменить.
3. **Редактор программ** — CRUD программ и интервалов (название, минуты, autoNext, повторы), выбор программы по умолчанию.
4. **Статистика за день** — счётчик отданных кальянов за смену, разбивка по столам. Локально, без выгрузки.

## Технические требования

- Адаптивная вёрстка: телефон / планшет / десктоп-монитор за баром.
- Таймеры считаются от абсолютных timestamp'ов — переживают перезагрузку страницы и засыпание вкладки.
- Всё состояние в localStorage, восстановление сессии после F5.
- Синхронизация между вкладками: приложение, открытое в нескольких вкладках, не затирает состояние.
- На узком экране (телефон) свободная раскладка заменяется потоком кружков.
